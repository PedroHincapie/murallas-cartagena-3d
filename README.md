# Murallas de Cartagena de Indias en 3D

Comparación de dos modelos de IA con el mismo contexto (un JSON histórico verificado, con cada dato marcado como EXACTO o APROXIMADO) y el mismo prompt: construir una réplica 3D fiel de las murallas en un solo HTML con Three.js.

- [Claude Opus 5.5](claude/)
- [Gemini 4 Argon](gemini/)
